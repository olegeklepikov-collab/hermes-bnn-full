## Скачать всё

Полный комплект находится в **Releases этого репозитория**, частями одного tar.gz. Он включает само ядро и исходники, среды Python/Java/Node, Memory, AgentMemory, Graphiti/Neo4j, Zvec, Cognee, Serena, Mirage, Beads/Dolt, GSD, подписанные Research/Foundation, R и официальный установщик R.app, Zotero, ASReview/Dory, документарный runtime, исследовательские адаптеры, Intake и инструкции. Предыдущие закрытые репозитории для развёртывания не нужны.

Git содержит проверяемые исходники прикладных компонентов, Intake, инструменты установки, нейтральные конфигурации и полные манифесты. Многогигабайтные бинарные среды находятся в частях выпуска, а не в Git. Один `git clone` не равен полной установке. [Открытый выпуск](https://github.com/olegeklepikov-collab/hermes-bnn-full/releases/latest), [закрытый выпуск](https://github.com/olegeklepikov-collab/hermes-bnn-full-private/releases/latest).

Согласованная пара: **Memory 2.0.0-dev.44 + Intake 0.14.3**. GSD Engine 3.0.3, Research 0.44.0b2, Foundation 0.14.0b1. Это явно обозначенная местная сборка с закреплёнными интерфейсами; неподтверждённое обновление upstream поверх неё не является безопасным обновлением.

Открытый и закрытый репозитории содержат идентичный обезличенный программный комплект. Закрытая видимость не означает наличие дополнительных авторизаций или частной истории. Собственные облачные доступы и Telegram подключаются по инструкции. Поставщики могут ограничивать методы и планы; наличие адаптера не доказывает успешный вызов.

Лицензии отдельных включённых программ сохраняются. Общая новая лицензия на чужие компоненты этим репозиторием не назначается. Системная macOS и права на платные облачные услуги не входят.
