# Hermes BNN

Единый исходный репозиторий полной платформы. Активная разработка: `product/`. Нынешний комплект: Memory 2.0.0-dev.45, Intake 0.14.4, GSD 3.0.3, Research 0.44.0b2, Foundation 0.14.0b1.

Разработка, предвыпускные испытания и рабочий экземпляр разделены. Код допускается по точному коммиту и хешу полного комплекта. Поставки старой схемы сохранены в истории и старых каталогах; они не определяют новые исходники.

- [Порядок разработки и выпуска](docs/RELEASE_ENGINEERING_RU.md)
- [Критерии приёмки](docs/RELEASE_ACCEPTANCE.json)
- [Состав и закрепления](locks/product.lock.json)
- [Происхождение импортированных исходников](locks/source-import.json)

Начало работы: `python3 -B -m unittest discover -s tests/release_engineering -v`. Сборка из чистого коммита: `python3 -B packaging/release_cli.py build --version 2026.11.1`. Требуется локальная привязка путей, подписывающего ключа и проверенного окружения из `.operator/resources.json` вне Git. Значения доступов не входят в репозиторий или нейтральный дистрибутив.

Первая интегрированная поставка имеет статус кандидата. Успех автономной установки не объявляет завершёнными сетевые и модельные испытания. Рабочая установка не обновляется этим репозиторием автоматически.
