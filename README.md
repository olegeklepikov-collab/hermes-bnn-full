# Hermes BNN

Единый исходный репозиторий полной платформы. Активная разработка: `product/`. Активные исходники: Memory 2.0.0-dev.47, Intake 0.14.6, GSD 3.0.3, Research 0.44.0b2, Foundation 0.14.0b1.

Разработка, предвыпускные испытания и рабочий экземпляр разделены. Код допускается по точному коммиту и хешу полного комплекта. Поставки старой схемы сохранены в истории и старых каталогах; они не определяют новые исходники.

- [Порядок разработки и выпуска](docs/RELEASE_ENGINEERING_RU.md)
- [Критерии приёмки](docs/RELEASE_ACCEPTANCE.json)
- [Состав и закрепления](locks/product.lock.json)
- [Происхождение импортированных исходников](locks/source-import.json)

Начало работы: `python3 -B -m unittest discover -s tests/release_engineering -v`. Сборка из чистого коммита: `python3 -B packaging/release_cli.py build --version 2026.11.3`. Требуется локальная привязка путей, подписывающего ключа и проверенного окружения из `.operator/resources.json` вне Git. Значения доступов не входят в репозиторий или нейтральный дистрибутив.

Первая интегрированная поставка имеет статус кандидата. Успех автономной установки не объявляет завершёнными сетевые и модельные испытания. Рабочая установка не обновляется этим репозиторием автоматически.

Полный интегрированный кандидат: [BNN 2026.11.1 candidate.1](https://github.com/olegeklepikov-collab/hermes-bnn-full/releases/tag/bnn-2026.11.1-candidate.1). Это самостоятельный комплект для испытаний, без прежней основы и отдельных исправлений. Рабочий экземпляр автоматически не обновляется.

Дополнительное настоящее испытание кандидата Memory dev.45 обнаружило отсутствие чтения дочернего продукта родителем. Исправление dev.46 включается в новый полный кандидат; публикация исходников не означает производственный допуск.
