# Hermes BNN Intake 0.14.3, полная переносимая поставка

Согласованная пара: Memory 2.0.0-dev.44 + Intake 0.14.3. Это отдельная квалификация полной платформы, производная от самостоятельного Intake 0.14.2. Алгоритмы Intake сохранены; изменилась привязка к переносимой основе и соответствующее испытательное окружение.

Полная установка: [../docs/INSTALL_MACOS.md](../docs/INSTALL_MACOS.md). Она сама подключает Intake. Отдельное сопровождение: [INTEGRATION.md](INTEGRATION.md). Архитектура, 120 требований и точные схемы: `docs/ARCHITECTURE.md`, `docs/REQUIREMENTS.json`, `docs/TOOL_CATALOG.json`. Текущая проверка пакета: `tools/verify_package.py`; испытания: `tools/run_native_tests.py`.

Семь инструментов и открытый каталог методов, шесть профилей, атомарная декомпозиция, документы, опрос и его ограничения, восполнение лакун, делегирование и автономная системная приёмка работают через один существующий Host/Store. Режимы `/intake off`, `/intake auto`, `/intake on`; новые беседы начинают с off. Внешнее человеческое ревью рекомендуется адресно и не блокирует выпуск.

В `provenance` и `packages/manifest-0.14.2.json` сохранены явно обозначенные свидетельства предшествующей поставки. Они не являются манифестами текущих байтов. Пользовательские ключи, личность, данные и история отсутствуют.
