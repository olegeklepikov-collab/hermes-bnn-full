# Чтение результатов дочерних исполнителей

Исходный отказ воспроизведён в полном кандидате Memory dev.45: доверенный запуск и один реальный вызов модели завершились SUCCEEDED, продукт 13+29=42 сохранён, но parent получал только идентификаторы/состояния. Операторское чтение SQLite не засчитывается как передача агенту.

В dev.46 общий Team.result используется и обычным Hermes work_team, и UDR udr_team. После status передайте action=result, task_id, expected_revision, offset=0, page_size<=8192. В UDR нужен run_id. Все страницы должны иметь одинаковые revision/product_sha256. Продолжайте по next_offset, пока has_more=true; объедините text. complete=true означает, что весь продукт находится в одном этом ответе. page_reaches_end означает только конец представления.

Возвращается канонический JSON сохранённого типизированного продукта, а не побайтовый исходный текст модели. product_sha256 проверяет это представление; native_output_sha256 относится к исходному выводу исполнителя. Наличие succeeded или окончание страниц не доказывает научную корректность.

Чужой профиль/сеанс/работа, неверная редакция и незавершённый продукт запрещены. Не выдаются capability и полный handle. Чтение завершённого/приостановленного UDR не обновляет срок, не запускает работников и не создаёт новых исследований. Выключенный исследовательский модуль остаётся выключенным.

Проверки SQLite: малый продукт, большое Unicode-содержимое без потерь, чужая область, смена редакции, незавершённый исполнитель/needs, некорректные границы, пустая последняя страница, повреждённая привязка и общий маршрут обычной/завершённой исследовательской работы. Нативная приёмка выполняется на новом полном архиве; установка слоя поверх рабочего BNN не предусмотрена.
