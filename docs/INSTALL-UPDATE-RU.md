# Установка и обновление цельного выпуска

Новая установка: [полная инструкция macOS](../product/docs/INSTALL_MACOS.md). Исторические основы и отдельные исправления не накладываются.

Для существующего владельца используйте `packaging/upgrade_existing.py` из исходников выпуска. Он проверяет точную поддержанную пару Memory/Intake, подпись цельного архива, создаёт резерв и отдельно репетирует миграцию. Собственный шлюз должен быть свободен и штатно остановлен; записи другого владельца и ключи не импортируются. Разрешение на обновление рабочего экземпляра и точная область записываются в отдельный операторский файл. Сначала проверяйте ту же операцию на собственной тестовой копии. Не запускайте первичный install.sh поверх существующего профиля.

Команды и политика восстановления: [разработка и хранение](DEVELOPMENT_AND_STORAGE_RU.md), [резерв и восстановление](../product/docs/BACKUP_RECOVERY.md). Прежняя цепочка файлов сохранена как [история](history/INSTALL-UPDATE-before-20261104.md).
