# Полный программный состав

Все перечисленные каталоги находятся внутри полного архива. В Git размещены инструкции, проверяемые источники адаптеров, Intake и манифесты; большие двоичные среды находятся в Releases того же репозитория.

| Компонент | Путь в комплекте | Состав |
|---|---|---|
| Hermes | `Hermes/hermes-agent` | Полные исходники, собственная venv и исправления ядра |
| Memory / context / identity | `Hermes/Memory/releases/2.0.0-dev.46` | Один общий Host, Store, parser/compute, контексты, режимы и пустое основание новой идентичности |
| Intake | `Intake` | Исходники, wheel 0.14.4, схемы, каталог методов, тесты и установщик |
| Python | `Hermes/runtime/python` | Самодостаточный CPython 3.14.6 и среды компонентов |
| GSD | `Hermes/GSD` | Канонический Engine 3.0.3 и адаптер r6; источник проверяется отдельно |
| Research + Foundation | `Hermes/UDR/software` | Подписанные ZIP, подписи, публичные ключи и исходные деревья |
| Beads | `Hermes/Beads` | Исполнитель 1.3.1 и средства основных задач |

| Средства сопровождения сервисов | `Hermes/Development` | Операторский код, защищённый ввод и OAuth; без авторской истории испытаний |

Манифест каждого файла, режима и относительной ссылки: `bundle-manifest.json`. Источники поставщиков и их собственные лицензии сохранены. Единую новую лицензию на чужие программы этот комплект не назначает. macOS и платные облачные продукты не являются частью дистрибутива.

## Состояния подключения

Программный состав включён. При установке создаются собственные подключения местных служб и один общий плагин. Сетевые ключи/OAuth, Telegram, облачное хранение и права доступа к конкретным научным данным новый владелец настраивает отдельно. Наличие схемы не доказывает успех внешнего вызова.
