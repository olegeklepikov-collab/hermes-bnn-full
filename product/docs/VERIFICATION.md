# Фактическая проверка полной поставки

Проверена собственная отдельная копия, без изменения действующих BN, BNN и UDR. Исходное состояние нового владельца создавалось заново. Результат относится к установке и местной регрессии; он не переносит авторские аккаунты и не объявляет завершённым научное исследование.

| Проверка | Фактический результат |
|---|---|
| Исходный нейтральный базовый комплект | Сверен полный исходный манифест перед объединением слоёв |
| Состав полной платформы | Файлы, байты, режимы и относительные ссылки описаны в окончательном `bundle-manifest.json` |
| Подписи поставщиков | Согласованные Research/Foundation проверены minisign и по исходным файлам; канонический GSD 3.0.3 проверен штатно |
| Чистая инициализация | Новые UUID/ключи и пустые первичные записи; CLI, Beads 1.3.1 и Dolt 2.4.2 действительно запущены |
| Общий Host и Intake | Один плагин, подключён Intake 0.14.3; пять обязательных контроллеров зарегистрированы; непривязанные действия отклонены |
| Регрессия Intake | **363/363 успешно**, исходники нативных зависимостей и входы испытаний не изменились |
| Документы | Нативные изолированные разборщики, адресные части, происхождение, покрытие, испорченные входы и корпус 1000 файлов входят в регрессию; извлечение не выдано за модельное чтение |
| Перенос parser/compute | Собственный корень принят; чужой owner_id, отсутствующая привязка, иной исполнитель и чтение исходной авторизации отклонены |
| AgentMemory / III | Настоящий запуск и health: healthy; собственное пространство |
| Graphiti / Neo4j | Настоящий запуск и health: healthy |
| Zvec | Настоящая локальная проверка: healthy, 0.7.0; модельное пространство 1024, без объявления внешнего вызова |
| R | Официальный установщик подписан/нотариализован; R 4.6.1 и ggplot2 4.0.3; среднее 3, выборочная дисперсия 2.5 |
| Zotero | Исходная подпись корректна; 788 обычных файлов сверены без изменения байтов. GUI/API в испытательном облачном каталоге **не подтверждены**: macOS остановилась в LaunchServices на sandbox extension |
| Внешние сервисы и модели | Схемы/адаптеры включены; новых ключей нет. Настоящие модельные, Voyage, исследовательские и Telegram-вызовы нового владельца здесь не заявлены |
| Другой физический Mac | Не проверен; испытание отдельной папки не заменяет другую машину |

Ранее обнаруженные дефекты экспортирования R, родительского каталога установки Intake, объявленной области ASReview-runtime и посторонних файловых атрибутов приложения исправлены. Неуспешные испытания сохранены отдельно и не включены как пользовательская история в публичный пакет. Код GSD и подписанных SDK не изменялся. Дополнительные локальные проверки импорта отражены в `VERIFICATION.json` после фактического выполнения.

Окончательное восстановление из архива и сверка загруженных частей фиксируются в наружном `PUBLICATION.json` выпуска: этот файл создаётся после формирования архива и не включается в собственный хеш. Проверка целостности не доказывает смысловую правильность всех будущих исследовательских результатов. Система должна различать фактическое чтение, поиск, проекцию и приёмку каждой новой работы.

Обнаруженное при первом восстановлении различие NFC/NFD в именах трёх файлов устранено в проверяющем установщике. Содержимое и исходные имена GSD не переписаны: сравнивается каноническая идентичность имени macOS, байты остаются строго проверяемыми. Четыре отдельные проверки подтверждают допустимость эквивалентного имени и отказ при коллизии, изменении байтов и лишнем файле.
