# Действующая установка и обновление

Для новой установки нужен один [полный выпуск](INSTALL_MACOS.md). Исторические основы и отдельные исправления не применяются. Существующие данные восстанавливаются по [BACKUP_RECOVERY.md](BACKUP_RECOVERY.md); переустановка поверх профиля запрещена. Прежняя схема сохранена как [история](history/INSTALL-UPDATE-before-20261104.md).
