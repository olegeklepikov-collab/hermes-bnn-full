# Обезличивание и происхождение

Поставляется программная часть для нового владельца. Не включены действующие data/auth.json, .env с ключами, приватные ключи подписи, токены Telegram, Voyage и поисковых сервисов, SOUL/глубокая идентичность автора, базы памяти, документы, проекты, библиотека Zotero, пользовательские векторы, журналы бесед и история Git автора.

Исходники компонентов, их лицензии, авторство, публичные ключи проверки, тестовые синтетические примеры и описания форматов ключей сохраняются. Публичный тестовый RSA-образец в документации OpenSSL не является секретом владельца. Прежние контрольные суммы в явно названном provenance относятся к происхождению, а не к текущему выпуску.

В 20 неподписанных квитанциях сборки Homebrew личный домашний путь заменён на `__BUILD_USER_HOME__`; код и двоичные файлы не изменялись. Посторонние FinderInfo/ResourceFork в копии Zotero исключаются, чтобы сохранить проверяемость исходной подписи; подпись приложения не заменяется самодельной. Архив формируется без расширенных атрибутов macOS.

Запечатанные дескрипторы native parser/compute могут содержать исходный путь программного корня как происхождение. После инициализации проверяемый адаптер связывает этот корень с текущим каталогом и UUID нового владельца. Это не доступ к прежним файлам. Проверки чужого владельца, неверного исполнителя, отсутствующей привязки и чтения исходной авторизации должны отклоняться.

Memory dev.44 является явно отмеченной местной производной dev.43: адаптер подтверждённого переноса пути применяется также к compute; содержание GSD и подписанных SDK не изменено. Intake 0.14.3 сохраняет алгоритмы 0.14.2 и закрепляет новую совместимую основу. Этот новый парный выпуск не переписывает отдельные репозитории Intake 0.14.2 и не меняет действующий BNN.

Публичная и закрытая копии побайтно совпадают по программному комплекту. Закрытый репозиторий не предназначен для загрузки действующих секретов. Для собственного приватного состояния нужен отдельный зашифрованный резерв.
