# Memory 2.0.0-dev.54

Текущая совместимая пара: Intake 0.14.14. Устанавливается в составе одного полного проверенного выпуска Hermes BNN; ручная цепочка исправлений не требуется.

Подтверждённая цель хода больше не зависит от сменяемого токена контекста. Обновление первичных данных или Intake и повторное сжатие сохраняют возможность продолжения. Новый ход, другая работа, повреждённая контрольная точка и отсутствие подлинного подтверждения не заимствуют прежний допуск.

Исторические записи читаются без изменения их схемы и содержимого. Текущие полномочия, доступность источников, неизвестные эффекты и расходы проверяются отдельно. Системный промпт не меняется, внешние действия при восстановлении не повторяются.

Объём чтения сохранённых сервисных ответов определяется задачей и её контрактом. Частичный просмотр не выдаётся за полное чтение.

Прежние подтверждённые выпуски и операторские резервные точки сохраняются. При смене программы нельзя откатывать новые пользовательские данные.
