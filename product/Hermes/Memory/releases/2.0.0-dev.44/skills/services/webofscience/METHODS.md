## Полный каталог объявленных методов

- `service_status`: read. Состояние подготовки Web of Science, письменного разрешения на ИИ и ключей. Не запрашивает данные Clarivate.
- `capability_catalog`: read. Официальные варианты доступа, подготовленные методы и профили. Наличие схемы не означает работающую подписку.
- `query_plan`: read. Местный план исследования и запросов Web of Science; API не вызывается и данные базы не читаются.
- `access_request`: write. Получить местный проект обращения в Clarivate о письменном разрешении на использование API с языковой моделью. Ничего не отправляет.
