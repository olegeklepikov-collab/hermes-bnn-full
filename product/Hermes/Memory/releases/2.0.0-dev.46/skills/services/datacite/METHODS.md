## Полный каталог объявленных методов

- `api_dois_get__dois`: read. Return a list of DOIs.; GET /dois
- `api_dois_id_get__dois_id`: read. Return a DOI.; GET /dois/{id}
- `api_clients_get__clients`: read. Return a list of clients (repositories).; GET /clients
- `api_clients_id_get__clients_id`: read. Return a client.; GET /clients/{id}
- `api_clients_totals_get__clients_totals`: read. Return clients DOI production statistics.; GET /clients/totals
- `api_prefixes_get__prefixes`: read. Return a list of prefixes.; GET /prefixes
- `api_prefixes_id_get__prefixes_id`: read. Return a prefix.; GET /prefixes/{id}
- `api_prefixes_totals_get__prefixes_totals`: read. Return prefixes DOI production statistics.; GET /prefixes/totals
- `api_providers_get__providers`: read. Return a list of providers (including members and consortium organizations).; GET /providers
- `api_providers_id_get__providers_id`: read. Return a provider.; GET /providers/{id}
- `api_providers_totals_get__providers_totals`: read. Return providers DOI production statistics.; GET /providers/totals
- `api_events_get__events`: read. Return a list of events.; GET /events
- `api_events_id_get__events_id`: read. Return an event.; GET /events/{id}
- `api_heartbeat_get__heartbeat`: read. Return the current status of the REST API.; GET /heartbeat
- `api_client_prefixes_get__client_prefixes`: read. Return a list of client-prefixes.; GET /client-prefixes
- `api_provider_prefixes_get__provider_prefixes`: read. Return a list of provider-prefixes.; GET /provider-prefixes
