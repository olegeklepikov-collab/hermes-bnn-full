# Memory 2.0.0-dev.12 — нативный допуск MCP

Подготовленная подпись не разрешает RPC: сервер сверяет окончательную нативную попытку, текущие полномочия и точные полученные аргументы. Доставка закрепляется один раз до операции. Каталог публикует только явно объявленные инструменты: сейчас 7 из 20 определений, 11 правил.

Фоновые адаптеры и сетевое получение векторов требуют отдельного разрешения операции и отпечатка ресурса. В закрытой BNN разрешений нет. Отсутствующая/неверная политика не блокирует местную первичную память; очередь сохраняется, кэш не вызывает сеть.

227 целевых проверок (19 новых) и 36 проверок памяти прошли. Ядро не изменялось. Новая memory-dev12 сохраняет 63 редакции/21 таблицу; новая таблица RPC пуста, допуски не придуманы. Производственные BN/UDR и общий development lock не изменены. Полная W1 остаётся открытой.
