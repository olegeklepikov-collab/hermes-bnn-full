## Полный каталог объявленных методов

- `service_status`: read. Состояние режимов и ограничения трёх площадок. Не обращается к их сайтам.
- `source_options`: read. Возможности площадки, официальные инструкции и основания доступа.
- `query_plan`: read. План поиска: внешние запросы и отдельные действия в официальном интерфейсе.
- `search_candidates`: read. Внешний поиск через Tavily Search по домену площадки. Только отрывки указателя; оригинал не читается.
- `resolve_doi`: read. Проверка DOI по официальным метаданным Crossref; не чтение статьи или целевой площадки.
- `import_document`: blocked. Добавить законно полученный местный PDF/TXT/MD/CSV/RIS/BibTeX из папки inbox. Файл этим инструментом не скачивается и не загружается в облако. Выбранные впоследствии отрывки возвращаются модели Hermes. Основание использования указывает владелец.
- `document_info`: blocked. Местные сведения о документе, происхождение, контрольная сумма, объём извлечения. Сам текст не читается.
- `read_pages`: blocked. Прочитать извлечённый текст выбранных физических страниц местного документа. Изображения, таблицы и весь документ этим не проверяются.
- `find_in_document`: blocked. Найти буквальную фразу в извлечённом местном тексте с контекстами и страницами. Это поиск внутри полученного файла, не корпуса площадки.
- `export_document_metadata`: blocked. Сохранить местную карточку с происхождением в JSON или RIS. Сведения владельца не превращаются в проверенную библиографию.
- `permission_request`: write. Подготовить текст обращения о разрешении на доступ и применении в бизнесе; сохраняет местный файл, ничего не отправляет.
