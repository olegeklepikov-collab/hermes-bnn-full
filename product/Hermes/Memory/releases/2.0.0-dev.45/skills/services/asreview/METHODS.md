## Полный каталог объявленных методов

- `service_status`: read. Проверить местную установку ASReview, модели, каталоги и состояние LAB.
- `model_catalog`: read. Получить выбранные модели и их точные параметры; составные модели ASReview доступны отдельно.
- `inspect_dataset`: read. Проверить местный CSV/RIS/XLSX/TSV/JSON: поля, пропуски, метки и повторы названий.
- `prepare_dataset`: write. Создать нормализованную копию данных CSV; исходный файл сохраняется. Не превращает пропуски в исключения.
- `create_project`: write. Создать отдельный местный обзор или проверку ранее заданных меток; требуется протокол критериев перед реальными решениями.
- `list_projects`: read. Перечислить местные проекты ASReview без чтения статей.
- `project_info`: read. Получить параметры проекта, происхождение данных, модель и ход отбора.
- `list_records`: read. Прочитать ограниченную страницу импортированных названий и аннотаций с метками.
- `get_record`: read. Прочитать одну импортированную запись, историю решения и заметку; полный текст не загружается.
- `set_protocol`: write. Сохранить вопрос, критерии включения/исключения, этап и правила проверки и остановки. Не меняет научных решений.
- `get_protocol`: read. Прочитать сохранённый протокол отбора.
- `configure_model`: write. Выбрать подготовленную модель и начальное состояние генератора; прежние решения сохраняются.
- `train_rank`: write. Обучить модель по существующим двум классам и обновить приоритеты. Вероятности не означают научную достоверность.
- `next_records`: read. Получить очередные неразмеченные уникальные записи по последнему ранжированию; решения не записываются.
- `propose_decisions`: write. Сохранить предложения агента отдельно от подтверждённых меток; обучение по предложениям не запускается.
- `record_decision`: write. Записать или исправить явно заданное человеком решение либо синтетическую проверку; сохраняются причина, этап и история. Совпадающие записи получают общее решение ASReview.
- `progress`: read. Получить количества исходных/уникальных/размеченных записей и ограничения оценки полноты.
- `decision_history`: read. Прочитать изменения решений ASReview и журнал действий Hermes.
- `sample_audit`: read. Получить воспроизводимую случайную выборку ещё не просмотренных уникальных записей; ничего не исключать.
- `export_dataset`: write. Сохранить отбор в CSV/TSV/XLSX/JSON/RIS и отдельные исходные поля с историей; нерешённые записи остаются пустыми.
- `export_project`: write. Сохранить переносимую копию проекта .asreview с настройками, данными и решениями.
- `import_project`: write. Импортировать копию архива .asreview под новым идентификатором; исходный проект сохраняется, исполняемые файлы не принимаются.
- `simulate`: write. Смоделировать отбор на полностью размеченных данных с заданными моделью, начальными примерами и ограничением просмотра.
- `simulation_report`: read. Рассчитать фактически найденную долю релевантных записей и затраты просмотра только для полностью размеченного моделирования.
- `compare_decisions`: read. Сравнить текущие решения с исходными метками для режима проверки; согласие не доказывает правильность критериев.
- `set_review_status`: write. Отметить обзор завершённым либо возобновить; это не подтверждает полноту найденных исследований.
- `plot_progress`: write. Создать изображение накопленного числа включённых записей по порядку подтверждённых решений.
- `read_documentation`: read. Прочитать ограниченный фрагмент сохранённой официальной инструкции ASReview 3.0.8.
- `create_demo`: write. Создать отдельный синтетический набор и проект для проверки интерфейса; научных публикаций в нём нет.
