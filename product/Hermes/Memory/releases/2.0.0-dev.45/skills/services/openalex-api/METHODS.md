## Полный каталог объявленных методов

- `service_status`: read. Проверить личный ключ, бесплатный остаток, тариф и собственные ограничения; ключ скрывается.
- `list_entities`: read. Полный официальный API поиска и фильтров по 26 активным типам сущностей. Полный текст поиска не равен чтению статьи.
- `get_entity`: read. Полные метаданные по OpenAlex ID или DOI/PMID/PMCID/ORCID/ROR/ISSN, с исходными полями.
- `batch_entities`: read. До 100 однотипных OpenAlex ID через OR; вернуть покрытие и отсутствующие записи без выдумывания.
- `group_entities`: read. Группировки и числа по полю; фиксировать корпус, пропуски, перекрытие групп и страницы.
- `semantic_search`: read. Поиск работ по смыслу: до 50 результатов, запрос до 2000 знаков; не оценка научной достоверности.
- `autocomplete`: read. Подсказки имён сущностей и идентификаторов; совпадение имени не подтверждает личность.
- `read_abstract`: read. Восстановить порядок слов индексированной аннотации и прочитать ограниченный фрагмент.
- `work_links`: read. OA, версии, лицензии, источники и доступность PDF/TEI. Не скачивает и не читает тексты.
- `work_metrics`: read. Счётчики, динамика, FWCI и процентили OpenAlex; не качество или поддержка научного вывода.
- `citations`: read. Входящие цитирования, внесённые исходящие ссылки или похожие работы; по умолчанию краткие записи, дополнительные поля через select. Контексты цитирования не предоставляются.
- `translate_query`: read. Проверить и перевести OQL/OQO бесплатно, без исполнения; сохранить цену и предупреждения.
- `execute_query`: read. Выполнить проверенный OQL/OQO с вложенной логикой, группировками и расчётами, в пределах бесплатного бюджета.
- `classify_text`: read. Классифицировать предоставленный публичный/согласованный текст по темам и ключевым словам; текущая модель октября 2026. Закрытый текст не передавать автоматически.
- `download_content`: write. Один доступный оригинальный PDF или GROBID TEI из OpenAlex; личный ключ, контроль расходов, 50 МБ, без передачи ключа хранилищу.
- `content_structure`: blocked. Структура местного GROBID TEI: разделы и таблицы. Это машинное извлечение, не издательский XML.
- `read_content`: blocked. Прочитать ограниченный раздел, аннотацию или таблицу TEI; сложные таблицы сверять по PDF.
- `read_pdf_pages`: blocked. Прочитать текст указанных страниц оригинального PDF с 1, не более 10; распознавания сканов нет.
- `render_pdf_page`: blocked. Изображение страницы исходного PDF для проверки таблиц и рисунков.
- `export_results`: write. Сохранить полученную страницу метаданных/групп в JSON, JSONL или CSV; не объявлять полной выгрузкой.
- `save_query`: write. Сохранить проверенный OQL/OQO и его происхождение местным файлом на AgentRuntime2; не создаёт почтовых уведомлений.
